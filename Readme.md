# Code Quality Refactoring Exercises

## Overview

This project contains a set of JavaScript exercises focused on improving code quality through refactoring.  
The goal is to enhance readability, maintainability, and modern JavaScript practices.

Each function was refactored to:
- Improve structure and readability
- Reduce unnecessary complexity
- Use modern JavaScript features
- Ensure safer and cleaner logic

## Exercises

### Exercise 1: Calculate Average
Refactored loop-based logic for better structure and readability.

### Exercise 2: Greet User
Simplified conditional logic for cleaner return statements.

### Exercise 3: Reverse String
Improved string reversal using cleaner iteration logic.

### Exercise 4: Find Even Numbers
Refactored to use clearer filtering logic.

### Exercise 5: Calculate Factorial
Improved loop-based factorial calculation and removed unnecessary branching.

### Exercise 6: Find Maximum Number
Simplified nested conditionals for clearer comparison logic.

### Exercise 7: Multiply Numbers
Clean and minimal function for multiplication.

### Exercise 8: Calculate Discount
Improved conditional logic and readability for pricing rules.

### Exercise 9: Calculate Matrix Sum
Refactored nested loops for better structure and clarity.


## Key Improvements

- Replaced `var` with modern variable handling (`let/const`)
- Reduced nested conditionals
- Improved naming and structure
- Applied array methods where appropriate
- Simplified logic for readability
